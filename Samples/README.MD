# Phishing Sample Artifacts
This directory contains the raw phishing email samples analyzed in this project. 

**Safe Handling Notice:** 
To prevent accidental execution on host machines, all raw `.eml` files have been compressed into a password-protected archive (`phishing_eml_samples.zip`). 
* **Password:** `infected`

## Dataset Attribution
The artifacts in this directory were sourced from the [phishing_pot](https://github.com/rf-peixoto/phishing_pot) repository curated by rf-peixoto. They are hosted here strictly for defensive security research, log parsing demonstration, and portfolio documentation.
