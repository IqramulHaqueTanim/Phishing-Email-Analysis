# Phishing Email Triage & Threat Intelligence Portfolio


## Project Objective
This repository serves as a practical demonstration of Security Operations Center (SOC) triage, email header forensics, and threat intelligence pivoting. The portfolio spans five distinct attack profiles analyzed from raw `.eml` artifacts to full incident reports, illustrating the diagnostic workflows required to detect, analyze, and document modern email-borne attacks.

## Portfolio Scenarios

**[Case 01: Malware Delivery & Attachment Triage (`quotation.iso`)](Reports/Case-01.md)**
* **Focus:** Malicious file delivery mechanisms and attachment extraction.
* **Key Findings:** Identified a weaponized disk image attachment (`quotation.iso`) masquerading as a business quote, analyzed RFC 822 MIME part structure, and isolated initial-access payloads.

**[Case 02: Netflix Impersonation & Redirect Triage](Reports/Case-02.md)**
* **Focus:** High-volume consumer credential harvesting and domain spoofing.
* **Key Findings:** Traced display name spoofing against Netflix billing, extracted evasive landing URLs, verified dead-drop infrastructure on URLScan.io, and mapped compromised sender domains.

**[Case 03: Binance Impersonation & Cloud Infrastructure Abuse](Reports/Case-03.md)**
* **Focus:** Weaponization of legitimate cloud services (Amazon SES & AWS S3).
* **Key Findings:** Evaluated SPF/DKIM passes generated by trusted Amazon SES relays, uncovered credential phishing hosted directly inside an Amazon S3 bucket, and documented the challenges of IP reputation whitelisting.

**[Case 04: Sextortion, Credential Stuffing & Blockchain Tracking](Reports/Case-04.md)**
* **Focus:** Text-only psychological extortion and cryptocurrency tracing.
* **Key Findings:** Loaded artifacts into PhishTool to evaluate self-spoofed headers, investigated breach-sourced credentials (`Aur****20!!!`), and tracked on-chain transaction flows across the attacker's Bitcoin wallet to confirm over $3,300 USD extorted.

**[Case 05: CAA Impersonation & Bayesian Poisoning (Hash Busting)](Reports/Case-05.md)**
* **Focus:** Brand impersonation, fear-based lures, and filter bypass tactics.
* **Key Findings:** Diagnosed DKIM cryptographic failures across mismatched third-party senders (`send.workwithshadow.com`), extracted malicious redirects (`cricktoon.org`), and documented hidden "hash-busting" padding injected to confuse Bayesian spam scoring.

## Methodology & Data Provenance 
The raw `.eml` artifacts analyzed in this portfolio were sourced from a sanitized honeypot repository. To ensure safe handling and prevent accidental execution of live artifacts, samples are archived in a password-protected `.zip` file (`infected`). Original recipient addresses were scrubbed and replaced with the `phishing@pot` placeholder prior to analysis. This sanitization does not affect the integrity of the attacker infrastructure, payload routing, or header forensics detailed in these reports.

## Key SOC Skills Demonstrated
* **Malicious Attachment Triage (Case 01):** Extracted and analyzed high-risk file attachments (like ISO disk images) used to bypass basic email filters and drop malware onto endpoints.
* **Email Authentication Checks (Cases 01–05):** Verified SPF, DKIM, and DMARC results to catch spoofing, header tampering, and unauthorized sending servers.
* **Header & Routing Analysis (Cases 01–05):** Traced the email path through the `Received:` headers to find the real origin IP address rather than trusting the display name or `From:` field.
* **Investigating Cloud Abuse (Case 03):** Analyzed how attackers abuse trusted platforms like Amazon SES and AWS S3 to pass email security filters and host phishing pages on legitimate infrastructure.
* **Blockchain Ledger Pivoting (Case 04):** Investigated extortion emails with no links by searching the attacker's Bitcoin wallet on a blockchain explorer, confirming transaction volume and payment activity.
* **Detecting Filter Evasion (Case 05):** Identified "hash busting" (randomized hidden text) used by spammers to confuse automated spam filters and alter email file hashes.
* **Threat Intelligence & SOC Tooling:** Combined automated Python scripts with enterprise platforms like PhishTool, CyberChef, URLScan.io, and VirusTotal to confirm malicious verdicts and verify infrastructure takedowns.
* **Actionable Reporting & Defense:** Mapped threats to the MITRE ATT&CK framework and documented clear remediation steps (firewall blocks, DMARC policies, and user awareness training).
