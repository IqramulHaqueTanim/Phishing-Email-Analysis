# Phishing Email Triage & Threat Intelligence Portfolio

## Project Objective
This repository serves as a practical demonstration of Security Operations Center (SOC) triage, email header forensics, and threat intelligence pivoting. The portfolio spans five distinct attack profiles analyzed from raw `.eml` artifacts to full incident reports, illustrating the diagnostic workflows required to detect, analyze, and document modern email-borne attacks.

## Tools & Technologies Used
* **Automation & Scripting:** Python 3 (`phishing_analyzer.py`), Linux CLI
* **Platform Triage:** PhishTool
* **Threat Intelligence & OSINT:** VirusTotal, URLScan.io
* **Blockchain Forensics:** Blockchain.com Explorer

---

## Portfolio Scenarios

**Case 01: Malware Delivery & Attachment Triage (`quotation.iso`)**
* **Focus:** Malicious file delivery mechanisms and attachment extraction.
* **Key Findings:** Identified a weaponized disk image attachment (`quotation.iso`) masquerading as a business quote, analyzed RFC 822 MIME part structure, and isolated initial-access payloads.

**Case 02: Netflix Impersonation & Redirect Triage**
* **Focus:** High-volume consumer credential harvesting and domain spoofing.
* **Key Findings:** Traced display name spoofing against Netflix billing, extracted evasive landing URLs, verified dead-drop infrastructure on URLScan.io, and mapped compromised sender domains.

**Case 03: Binance Impersonation & Cloud Infrastructure Abuse**
* **Focus:** Weaponization of legitimate cloud services (Amazon SES & AWS S3).
* **Key Findings:** Evaluated SPF/DKIM passes generated by trusted Amazon SES relays, uncovered credential phishing hosted directly inside an Amazon S3 bucket, and documented the challenges of IP reputation whitelisting.

**Case 04: Sextortion, Credential Stuffing & Blockchain Tracking**
* **Focus:** Text-only psychological extortion and cryptocurrency tracing.
* **Key Findings:** Loaded artifacts into PhishTool to evaluate self-spoofed headers, investigated breach-sourced credentials (`Aurora20!!!`), and tracked on-chain transaction flows across the attacker's Bitcoin wallet to confirm over $3,300 USD extorted.

**Case 05: CAA Impersonation & Bayesian Poisoning (Hash Busting)**
* **Focus:** Brand impersonation, fear-based lures, and filter bypass tactics.
* **Key Findings:** Diagnosed DKIM cryptographic failures across mismatched third-party senders (`send.workwithshadow.com`), extracted malicious redirects (`cricktoon.org`), and documented hidden "hash-busting" padding injected to confuse Bayesian spam scoring.

---

## Methodology & Data Provenance 
The raw `.eml` artifacts analyzed in this portfolio were sourced from a sanitized honeypot repository. To ensure data privacy, the original recipient addresses were scrubbed and replaced with the `phishing@pot` placeholder prior to analysis. This sanitization does not affect the integrity of the attacker infrastructure, payload routing, or header forensics detailed in these reports.

## Key SOC Skills Demonstrated

* **Static File & Attachment Triage (Case 01):** Extracted and categorized suspicious file types (such as `.iso` container images) designed to bypass MOTW (Mark-of-the-Web) protections and deliver second-stage executables.
* **Email Authentication & Protocol Forensics (Cases 01–05):** Evaluated cryptographic headers including SPF host validity, DKIM signature verification, DMARC alignment (`p=reject`/`quarantine`), and `Return-Path` mismatches.
* **Multi-Hop Routing Analysis (Cases 02 & 05):** Traversed full `Received:` chains chronologically to separate untrusted client injection points from legitimate mail relay hops, identifying spoofed originating IPs.
* **Cloud Infrastructure Abuse Analysis (Case 03):** Documented modern evasion tactics where adversaries utilize trusted vendors (Amazon SES, AWS S3) to bypass reputation-based web gateways and automated AV scoring.
* **On-Chain Financial Tracking (Case 04):** Pivoted from non-link social engineering lures into public blockchain ledgers (Bitcoin), evaluating address transaction histories, aggregate volumes, and fund washing patterns.
* **Filter Evasion & Obfuscation Decoding (Case 05):** Identified MIME multipart manipulation and Bayesian poisoning (hash busting) designed to evade content-inspection engines, while extracting embedded redirects.
* **Tool Diversity & Workflow Adaptation:** Leveraged automated Python parsing scripts for fast terminal extraction, pivoted to PhishTool for unified visual header/body triage, and integrated external threat platforms (VirusTotal, URLScan.io) for live infrastructure verdicts.
* **Incident Documentation & MITRE ATT&CK Mapping:** Formatted technical IOC tables, defined actionable perimeter blocking rules, and mapped adversary actions across ATT&CK techniques (Initial Access, Defense Evasion, Reconnaissance, Resource Development).
